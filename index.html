Fuel Log

Every fill-up, every mile, every dollar — and the MPG to prove it.

Log a fill-up

A partial fill still counts in gallons and cost, but it has no MPG — and neither does the fill-up after it. MPG needs two consecutive full tanks.

Summary

MPG = miles since the previous fill-up ÷ gallons at this fill-up. The running average uses full-to-full segments only — never an average of rounded per-fill-up figures. Cost per mile is total cost ÷ total miles.

Bikes

Bikes live in the shared Pocket Garage roster — the same b1/b2/b3 list the other apps use. Add a bike here and it is added to that roster for every app. There is no delete-bike here: roster management belongs to the landing dashboard, so a mistyped bike is removed there, not here.

Your data

No account, no server, no sync. Your fill-ups live in this browser's local storage. Back them up with Export — one JSON file.

Export

The backup is the whole fuel log — every bike, every fill-up. The per-bike export below is one bike's fill-ups, as JSON or readable plain text.

Import

Import replaces the current fuel log. Export first if you want to keep it. Fill-ups pointing at a bike the shared roster doesn't have yet still load — they show under their roster key until that bike is added.

Try it out
